# Matriz de aceite — 20/10/2026

Esta matriz distingue implementação verificada localmente de homologação externa. Não constitui aceite comercial. O código cobre as Fases 0–8 e a preparação local da Fase 9; o ambiente Supabase completo e o deploy ainda dependem de configuração.

| Critério do pedido original      | Evidência disponível                                                                              | Pendência para aceite final                                                                                 |
| -------------------------------- | ------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| 1. Login real                    | Auth/SSR/getUser, sessões e RBAC implementados; fronteiras locais e suíte HTTP real preparada     | Executar login/refresh/logout/recovery/SMTP no Supabase; suíte `test:supabase:http` não executada sem stack |
| 2. Permissões                    | Testes SQL por cargo, revogação/sessões e grants/RLS; matriz de rotas inventariada                | JWT/PostgREST/Storage reais por cargo                                                                       |
| 3. CRUD persistente no Supabase  | CRUD exercitado no PostgreSQL isolado e serviços de servidor                                      | Homologar persistência via HTTP e tipos oficiais no Supabase                                                |
| 4. Reserva online real           | Fluxo público SQL, tokens/ownership/antispam e browser com adapters de teste                      | Turnstile e API Supabase reais, aceite da política publicada                                                |
| 5. Aprovação manual              | SQL transacional, histórico e idempotência aprovados                                              | Percurso autenticado nas telas reais                                                                        |
| 6. Conflitos impedidos           | GiST compartilhada e concorrência entre reservas/locações/bloqueios/manutenção                    | Repetir na versão PostgreSQL 17 alvo e em duas sessões HTTP                                                 |
| 7. Tarifas corretas              | Testes de centavos/períodos/DST/limites/descontos e snapshots                                     | Política comercial aprovada com amostras da empresa                                                         |
| 8. Pagamentos registrados        | SQL de confirmação, parcial/alocação/caução/restituição e locks                                   | Conferência operacional de caixa e conciliação manual                                                       |
| 9. Contratos PDF                 | Renderer real, fonte/licença, versões/hashes, worker/lease e exemplo fictício verificado          | Texto jurídico, assinatura manual e Storage privado real                                                    |
| 10. Vistorias/fotos persistentes | Checklist/imutabilidade/bytes/metadados/RLS e compensações testados                               | Upload/URL assinada reais, celular e restituição de arquivos pendentes                                      |
| 11. Relatórios reais             | Dez consultas SQL, competência versus recebimento, CSV paginado/auditado                          | Validar valores com dados fictícios conhecidos na stack real                                                |
| 12. Testes críticos              | Unitários, SQL isolado, navegador e standalone aprovados conforme [verification](verification.md) | pgTAP/HTTP Supabase e percurso completo sem adapters                                                        |
| 13. Sem erros TypeScript         | Typecheck strict e build aprovados                                                                | Gerar/integrar tipos oficiais e repetir na CI                                                               |
| 14. Build de produção            | Standalone testado, assets, worker PDF, fonte e OFL incluídos                                     | Construir e escanear imagem Linux no ambiente escolhido                                                     |
| 15. Segredos protegidos          | server-only, scanner/import graph, gate pré-build e de promoção, env ignorado                     | Configurar/rotacionar secrets do provedor, revisar Git/histórico/logs e acesso operacional                  |
| 16. Migrations reproduzíveis     | 25 migrations aplicadas do zero no PostgreSQL 18.4, 64 tabelas com RLS                            | PostgreSQL 17/Supabase, legado e janela de índices/backup                                                   |
| 17. Documentação atualizada      | Runbooks, APIs validadas, matriz RBAC/aceite, testes e pendências                                 | Registrar evidências externas e decisões da empresa                                                         |
| 18. Pronto para homologação      | Pacote, Dockerfile, CI, readiness, bloqueio de promoção e roteiro preparados                      | Provisionar homologação, responsáveis, domínio e configurações; depois obter aceite                         |

Decisões ainda necessárias: hospedagem/domínio/custos, repositório Git/remoto, credenciais por ambiente, regras e modelos aprovados, retenção/LGPD, RPO/RTO/backups e responsáveis pelos jobs/incidentes. Nenhuma dessas decisões foi presumida como aprovada.
